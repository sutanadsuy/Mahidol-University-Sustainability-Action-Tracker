# ทำเว็บจำลองต่อบน Mac

ไฟล์ชุดนี้คือเว็บจำลอง Mahidol Sustainability Action Tracker รุ่นล่าสุด ณ 21 ตุลาคม 2569 ยังไม่เชื่อม Google Sheets หรือ Apps Script จริง

## เปิดเว็บ

1. แตกไฟล์ ZIP แล้วเปิด Terminal ในโฟลเดอร์ `ux-mockup`.
2. พิมพ์ `bash start-mac.command` แล้วกด Enter.
3. เว็บจะเปิดที่ `http://127.0.0.1:4180/starter.html` ให้เปิดหน้าต่าง Terminal ค้างไว้ขณะใช้งาน.

สคริปต์จะใช้ Node.js หรือ Python 3 ที่มีอยู่ใน Mac ถ้าเครื่องยังไม่มีทั้งคู่ ให้ติดตั้ง Node.js จากเว็บไซต์ทางการ แล้วรันคำสั่งเดิมอีกครั้ง

## งานที่ทำถึงตอนนี้

- หน้าเว็บจำลองมี 7 หน้า: หน้าแรก, ภาพรวมงบและโครงการ, บันทึกผลรายเดือน, ติดตามแผนและผล, วางแผนโครงการ, รายงานย้อนหลัง, จัดการระบบ (แอดมิน)
- ช่องจำนวนเงินใส่เครื่องหมายคอมมาระหว่างพิมพ์
- ผู้รับผิดชอบโครงการแยกเป็น หลัก, รอง 1, รอง 2 แต่ละแถวมีชื่อและอีเมล
- ข้อมูลทดลองที่กรอกเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น จึงไม่ย้ายตาม ZIP นี้

## ถ้าหาแชทเดิมไม่เจอ

ลองลงชื่อเข้าใช้บัญชีและ workspace เดียวกับเครื่องเดิม แล้วดูทั้งรายการแชทใน Codex และ ChatGPT หากยังไม่พบ ให้เริ่มแชทใหม่ เปิดโฟลเดอร์ `ux-mockup` นี้ และบอกว่า: “ช่วยพัฒนาเว็บจำลอง Mahidol Sustainability Action Tracker ต่อจากไฟล์ในโฟลเดอร์นี้ เริ่มจากอ่าน START-HERE-MAC.md ก่อน”

ไฟล์หลักคือ `starter.html`, `starter.css`, `starter.js` และ `styles.css`; `server.cjs` ใช้เปิดเว็บผ่าน Node.js
